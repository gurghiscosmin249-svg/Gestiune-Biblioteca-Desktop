# Descrierea proiectului

**Tema:** Gestionarea unei biblioteci — proiectarea interfeței desktop în Figma.

## Scop
Realizarea unui prototip pentru evidența fondului de carte, a cititorilor și a împrumuturilor/retururilor.

## Funcționalități
1. Catalogul cărților: listare, căutare după titlu, autor sau ISBN și filtre.
2. Adăugarea cărților noi într-o fereastră modală: titlu, autor, ISBN, categorie, an, editură și exemplare.
3. Înregistrarea unui împrumut/retur: selectarea cititorului și cărții, data împrumutului și termenul de returnare.

## Instrumente
Figma, Git, GitHub și UML.
